CHaser Kyoto Web の遊び方

CHaser は、15×17マスの盤面上で2つのプログラム(COOLとHOT)が交互に1手ずつ行動し、 アイテムを取り合いながら相手を追いつめる対戦ゲームです。左のエディタに Python で作戦を書いて、 「対戦開始」で右側の盤面上で動かして確認できます。

勝敗条件

  • 相手の上にブロック(×)を置く → 即勝利
  • 自分がすでに置かれているブロックの上に乗ってしまう → 即敗北
  • 上下左右をすべてブロックで囲まれて動けなくなる → 敗北
  • 既定ラウンド数(マップごとに指定、既定は100)以内に決着がつかない場合は、アイテム獲得数が多い方の勝ち(同数なら引き分け)

1ターンの流れ

自分の番が来るたびに、まず await client.get_ready() を1回呼び、 その次に下の16種類の行動関数のうちちょうど1つを await つきで呼び出してください。 この順番を守らないと反則負けになります(本家のCHaserサーバーと同じ仕様です)。

よくある間違い: look / search も1回呼ぶごとに1ターン消費する「行動」です。 「4方向まとめてサーチしてから動く」ことはできません(1回サーチ ⇒ そのターンは終了 ⇒ 次のターンでまた get_ready() から)。複数方向を調べたい場合は、下の「searchで少し先まで探索する」 サンプルのように、数ターンかけて状態を持ちながら調べてください。

行動関数

updownleftright効果
walkwalk_up() / walk_down() / walk_left() / walk_right()1マス移動して、移動先を中心とした周囲9マスの情報を取得
looklook_up() / look_down() / look_left() / look_right()2マス先を中心とした周囲9マスを覗き見る(移動しない)

戻り値(周囲情報)

すべての行動関数は、9個の整数からなるリストを返します。並び順は次の通りです(自分から見た向き):

左上上右上
左(中央/常に0)右
左下下右下

値の意味: 0=何もない　1=相手ターゲット　2=ブロック　3=アイテム

await は必要?(実行モードについて)

画面右上のバッジで、今この端末がどちらのモードで動いているか確認できます。

  • 同期モード: SharedArrayBuffer が使える場合(GitHub Pagesなど、ふつうにインターネット越しに開いた場合はこちら)。 value = client.get_ready() のように、本家のCHaser.pyと全く同じ書き方でそのまま動きます。
  • 非同期モード: file:// で直接ファイルを開いた場合など、ブラウザの制約で SharedArrayBuffer が使えない場合はこちら。await の無いコードを検出すると、 呼び出している関数を自動的に async def にして await を補ってから実行します (プログラムのコード自体は書き換えません。実行時に一時的に変換するだけです)。

つまり、どちらのモードでも、await の無い本家スタイルのコードはそのまま動くはずです。 ただし非同期モードでの自動補完はあくまで簡易的な解析なので、複雑な書き方(ジェネレータの中で呼び出す、など) では補完できずに動かないことがあります。その場合は value = await client.get_ready() のように、 自分で await を付けてください。await を付けるスタイルはどちらのモードでも 確実に動くので、迷ったら付けておくのがいちばん安全です。

既存のCHaserクライアントからの移植

CHaser-Helper 同梱の CHaser.py(import CHaser して cl = CHaser.Client() と書くスタイル)は、ほぼそのままここで動かせます。

  • import CHaser と cl = CHaser.Client() にそのまま対応しています(実際のソケット接続やGUI表示は行わず、 このシミュレータの盤面に直接つながります)。引数を渡しても無視されます。
  • get_ready() / walk_up() などの個別メソッドに加えて、 文字列で指定する cl.cmd("gr") / cl.cmd("wu") 形式(本家CHaser.pyと同じ2文字コマンド)にも対応しています。
  • import CHaser をせず、あらかじめ用意されている client という変数をそのまま使うこともできます。
  • 非同期モードでは自動的に await が補われるので、基本的にはそのままで動きます。 うまく動かないときだけ、上の説明の通り自分で await を追加してみてください。
  • chaser-python-client(from client.ChaserClient import ChaserClient のように 別の場所からimportするスタイル)は、importパスが異なるため現時点では非対応です。 メソッド名は共通なので、import 部分を削って client 変数を使う形に書き換えれば動きます。

保存について

書いたコードは自動的にこのブラウザの localStorage に保存されます(このデバイス限定)。 別の端末で使う場合や、確実に残したい場合は「保存(.py)」でファイルにダウンロードしてください。 サーバー側には一切保存されません。
